# АҚШҰҚЫР — ЦИФРЛЫҚ ШЕЖІРЕ

**«Машырық қажыдан бүгінгі Ақшұқырға дейін»**

9-сынып оқушысының ғылыми-зерттеу жобасы — Ақшұқыр ауылының (Түпқараған ауданы, Маңғыстау облысы) тарихи мұрасын цифрлық форматта жүйелейтін интерактивті веб-платформа.

## Іске қосу

```bash
python -m pip install -r requirements.txt
python app.py
```

Содан кейін браузерде: **http://127.0.0.1:5000** · Windows үшін `run.bat`.

## Технология

- Backend: Python 3 + Flask
- Frontend: HTML5, CSS3, Vanilla JavaScript
- 3D: Three.js r128 + OrbitControls (локалды)
- Карта: Leaflet.js 1.9 + OpenStreetMap
- Анимация: CSS + IntersectionObserver

Барлық үшінші тарап библиотекасы `static/vendor/` — интернетсіз де жұмыс істейді.
